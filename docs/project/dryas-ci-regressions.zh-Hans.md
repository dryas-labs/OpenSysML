# 下游 CI 回归修复

[English](dryas-ci-regressions.md) | **简体中文**

本记录说明完整 PR 检查所暴露问题的修复，不宣称全量测试已通过。
不修改 benchmark 门槛、类别映射、裁定或下载的语料文件。

| 失败 | 修复及保留的检查 |
| --- | --- |
| 严格站点构建遗漏页面 | 按现有站点政策，将下游工程记录明确保留在仓库而不发布至网站，继续启用严格检查。 |
| Node 依赖安装失败 | 从已发布包补齐平台依赖锁记录，保留依赖版本并用干净 npm ci 验证。 |
| 自模型注册表不一致 | 将自模型 TypeCheckPass 标为 element-scoped，与实现保持一致。 |
| 标准库快照过期 | 使用维护版解析器重新生成派生快照，并与从源码重新加载的结果比较。 |
| 独立类型错误漏报、增量结果不一致 | 名称错误不再阻断整个文档的表达式检查；保留语法错误阻断，只抑制包含未解析输入的表达式诊断。 |
| cross feature 类型不一致 | 从所属 end 继承隐含类型，包括未显式指定类型的 part end 的 Parts::Part。 |
| 运行时样本 rad、min 名称冲突 | 显式选择 SI 单位，避免与 TrigFunctions::rad、QuantityCalculations::min 按导入顺序竞争；原数值和错误消息断言不变。 |
| 重绑定样本导入两个不同 Car | 将后备导入移至外层命名空间，实际测试词法遮蔽，保留对象身份和重绑定断言。 |
| 正向过滤样本同时导入两个不同 Good | 正向样本明确限定元数据引用；原冲突另设负例。正向样本仍必须仅拒绝 Bad。 |
| REPL 样本以 package 作为 part 类型 | 改为该 package 内真实的 part 定义，保留根导入隔离断言，并为文件路径加引号。 |
| SI 量纲断言依赖有歧义的类型名称 | 单独断言原始文本中的两个 MagneticDipoleMomentUnit 未解析引用；仅在量纲对照中明确限定原断言对应的 ISQElectromagnetism 类型，保留全部量纲断言，不修改内置库原文。 |

原生维护 CI 纳入这些回归组。评价整个变更仍需要更广的上游检查，
部分用例通过不能证明完全符合标准，也不能作为忽略其他失败的理由。
