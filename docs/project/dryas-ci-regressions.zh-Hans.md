# 下游 CI 回归修复

[English](dryas-ci-regressions.md) | **简体中文**

本记录说明完整 PR 检查所暴露问题的修复，不宣称全量测试已通过。
历史 M0 门槛、类别映射、裁定和分数均不变，下载的语料文件也未修改。引擎仓库自身的 census 纠正与新的参考对比记录在下文单独说明。

| 失败 | 修复及保留的检查 |
| --- | --- |
| 严格站点构建遗漏页面 | 按现有站点政策，将下游工程记录明确保留在仓库而不发布至网站，继续启用严格检查。 |
| Node 依赖安装失败 | 从已发布包补齐平台依赖锁记录，保留依赖版本并用干净 npm ci 验证。 |
| 自模型注册表不一致 | 将自模型 TypeCheckPass 标为 element-scoped，与实现保持一致。 |
| 标准库快照过期 | 使用维护版解析器重新生成派生快照，并与从源码重新加载的结果比较。 |
| 独立类型错误漏报、增量结果不一致 | 名称错误不再阻断整个文档的表达式检查；保留语法错误阻断，只抑制包含未解析输入的表达式诊断。 |
| cross feature 类型不一致 | 从所属 end 继承隐含类型，包括未显式指定类型的 part end 的 Parts::Part。 |
| 运行时样本 rad、min 名称冲突 | 显式选择 SI 单位，避免与 TrigFunctions::rad、QuantityCalculations::min 按导入顺序竞争；原数值和错误类别断言不变；诊断中的源码回显采用显式限定后的单位拼写。 |
| 将错误下标负例算作无诊断正例 | 按其已有运行时错误预期，精确断言对应的静态错误；确认两个负例都实际检查，其余示例仍要求无表达式诊断。 |
| 重绑定样本导入两个不同 Car | 将后备导入移至外层命名空间，实际测试词法遮蔽，保留对象身份和重绑定断言。 |
| 正向过滤样本同时导入两个不同 Good | 正向样本明确限定元数据引用；原冲突另设负例。正向样本仍必须仅拒绝 Bad。 |
| REPL 样本以 package 作为 part 类型 | 改为该 package 内真实的 part 定义，保留根导入隔离断言，并为文件路径加引号。 |
| SI 量纲断言依赖有歧义的类型名称 | 单独断言原始文本中的两个 MagneticDipoleMomentUnit 未解析引用；仅在量纲对照中明确限定原断言对应的 ISQElectromagnetism 类型，保留全部量纲断言，不修改内置库原文。 |
| part 定义探针对合法模型要求报错 | 保留模型并要求完全无诊断。SysML §8.3.11.3 与 KerML §8.3.3.3.4 使其隐式具有 Parts::Part 类型；单列为“由构造满足”，不计入已观测的违规检出数量。 |

原生维护 CI 纳入这些回归组。评价整个变更仍需要更广的上游检查，
部分用例通过不能证明完全符合标准，也不能作为忽略其他失败的理由。

## 下游参考对比记录

原[上游记录](pilot-differential-baseline.json)保持不变。
[dryas-pilot-differential-baseline.json](dryas-pilot-differential-baseline.json)
来自对全部 380 个文件的实际重跑，参考版本仍为 Pilot 2026-08 / 0.62.0，
参考桥接代码、类别映射、标准库版本及语料版本不变。来源检查针对这个当前记录。
自模型字段纠正改变了输入，但 45 个自有示例的诊断没有变化。

报告的启动器标识省略平台专用的 `.exe` 后缀，实际调用仍使用完整文件名，以支持跨平台复现；统计前将诊断路径统一成仓库相对的正斜杠路径。
未能归属文件的模型诊断与 JVM 警告分别检查。
这个对比仅用于研究，独立于 M0 分数和引擎选择门槛。

逐组变化及具体行号见[英文表格](dryas-ci-regressions.md#downstream-reference-record)：

- SimpleQuadcopter、IndividualTest、ItemTest、PartTest 共减少 8 个 part 类型误报：维护版保留隐式的 Parts::Part 类型。
- constraints.sysml 和三个 specialization-cycle 探针共减少 8 个循环诊断：维护版接受合法特化循环，保留隐式基类型；原有多重性诊断仍保留。
- 两个 Vehicle 文件分别增加 6、18 个导入名称未解析诊断；Model Containment 和 Imports.kerml 各增加 3 个，均对应维护版已有的导入名称冲突行为。

合计减少 16 个诊断、增加 30 个导入名称诊断。100 个训练文件在两侧仍全部无诊断。
这些是对参考对比变化的解释，不是新的人工裁定，也不能据此宣称一般语义完全符合标准。
“只有某个引擎报告”的数量增减，本身不代表正确率变好或变差。
